# Sprint 1 — Technical Foundation

## Goal
Create a working React + Django REST + MySQL foundation.

## Stages
A — Backend setup, Django configuration, environment settings, database connection.

B — REST API foundation, health endpoint, error handling baseline, API versioning path.

C — React application shell, routing, API client, environment configuration.

D — Database migrations and baseline test setup.

## Acceptance
- Backend starts.
- Frontend starts.
- MySQL connection works.
- Migrations work from clean state.
- Frontend calls backend successfully.
- Baseline automated tests pass.

## Out of Scope
Business marketplace features.
