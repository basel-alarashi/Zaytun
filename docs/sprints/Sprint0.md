# Sprint 0 — Discovery & Foundation

## Goal
Turn the Zaytun idea into an intentional, reviewable project definition.

## Stages
### A — Product
- Finalize product vision.
- Finalize V1 boundary.
- Record locked decisions.

### B — Domain
- Establish glossary.
- Identify entities, ownership, lifecycles, invariants.
- Identify state machines.

### C — Architecture
- Decide frontend/backend/API/database boundaries.
- Create initial ADRs.

### D — Planning
- Build backlog.
- Build roadmap.
- Define DoD and review workflow.

## Exit Criteria
- Vision approved.
- Glossary approved.
- Requirements drafted.
- Architecture and data design reviewable.
- Backlog and roadmap reviewable.
