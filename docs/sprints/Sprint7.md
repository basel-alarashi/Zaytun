# Sprint 7 — Hardening & Release

## Goal
Produce a verified portfolio-quality V1 release.

## Review Areas
- Security
- Data integrity
- API contracts
- Automated tests
- Performance
- Responsive behavior
- Accessibility
- Error/loading/empty states
- Deployment
- Configuration/secrets
- Logging/recovery
- Documentation
- README/portfolio presentation

## Definition of Done
- Acceptance criteria satisfied.
- Build succeeds.
- Migrations succeed.
- Tests pass.
- No known critical defects.
- Authorization and validation verified.
- Affected docs updated.
- Release/deployment procedure documented.
- Final review evidence recorded.

## Explicit Rule
No major new feature enters this sprint unless it is required to satisfy the already-approved V1 scope.
