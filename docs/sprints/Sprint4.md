# Sprint 4 — Discovery & Cart

## Goal
Allow consumers to discover products and construct a valid single-farmer cart.

## Stages
A — Search/filter/pagination.

B — Product discovery API.

C — React catalog, product detail, storefront browsing.

D — Cart implementation.

E — Single-farmer constraint and checkout prevalidation.

## Acceptance
- Search works.
- Category filtering works.
- Cart CRUD works.
- Second-farmer product is rejected or requires defined cart replacement.
- Server remains authoritative for stock and price.
