# Sprint 3 — Farmers, Storefronts & Products

## Goal
Build the supply side of Zaytun.

## Stages
A — Farmer profile, storefront, categories, units, products.

B — CRUD APIs and ownership enforcement.

C — Farmer management UI.

D — Public storefront/product UI.

E — Validation and tests.

## Acceptance
- Farmer manages only owned products.
- Product price/stock/unit validation works.
- Consumer can view storefront and product.
- Availability is respected.
