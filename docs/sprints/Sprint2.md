# Sprint 2 — Identity & Access

## Goal
Make users, roles, authentication, and authorization reliable.

## Stages
A — User model and migrations.

B — Registration/login/logout/me API.

C — Consumer/Farmer/Admin authorization.

D — React authentication screens and protected routes.

E — Security and ownership tests.

## Acceptance
- Registration works.
- Login/logout works.
- Protected endpoints reject unauthenticated requests.
- Consumer/Farmer/Admin permissions differ correctly.
- Farmer cannot modify another farmer's resource.
