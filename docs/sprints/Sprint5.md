# Sprint 5 — Checkout, Payments & Orders

## Goal
Turn valid carts into orders and establish fulfillment/payment workflows.

## Stages
A — Address/order/payment schema.

B — Checkout/order APIs and transactions.

C — COD.

D — Sandbox payment if feasible.

E — Checkout/order UI.

F — Order lifecycle and farmer fulfillment.

## Acceptance
- Valid cart becomes order.
- Stock/price are revalidated server-side.
- Order preserves historical item information.
- Farmer can process/deliver order.
- Payment status is separate from order status.
